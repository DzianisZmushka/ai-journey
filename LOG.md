# \## День 2 — Линейная алгебра (3Blue1Brown, весь плейлист)

# 

# \### Что понял хорошо

# 

# \*\*Матрица = линейное преобразование.\*\* Столбцы матрицы — это места, куда попадают

# базисные векторы î и ĵ. Отсюда всё остальное читается без вычислений.

# 

# \*\*Два способа читать одну матрицу:\*\*

# \- по столбцам — куда уезжают базисные векторы (геометрия, для интуиции)

# \- по строкам — рецепт вычисления координат: первая строка даёт новый x, вторая новый y

# &#x20; (арифметика, для счёта)

# Оба верны. Путаница возникает при попытке считать по столбцам или рисовать по строкам.

# 

# \*\*Определитель\*\* — во сколько раз меняется площадь. Отрицательный = ориентация

# вывернулась. Ноль = плоскость схлопнулась.

# 

# \*\*Порядок умножения важен\*\*, потому что матрицы это последовательность действий,

# а действия не переставляются. Скобки при этом ничего не меняют: последовательность

# остаётся той же, меняется только что склеиваем заранее.

# 

# \*\*Скалярное произведение\*\* — мера согласованности направлений. Плюс — сонаправлены,

# ноль — перпендикулярны, минус — противоположны. Считается перемножением координат,

# геометрически = проекция × длина.

# 

# \*\*Векторное произведение\*\* — знаковая площадь параллелограмма. Антикоммутативно:

# смена порядка переворачивает знак. В 3D результат перпендикулярен обоим сомножителям.

# 

# \*\*Смена базиса.\*\* Матрица A, чьи столбцы — чужие базисные векторы в наших координатах,

# переводит ЕЁ числа в НАШИ. Обратно — через A⁻¹. Преобразование в её языке: A⁻¹MA,

# читается справа налево.

# 

# \*\*Собственный вектор\*\* — остаётся на своей прямой после преобразования, меняется только

# длина (или знак). Собственное значение — во сколько раз. У поворота на 90° вещественных

# нет: λ² = −1. Это корректный результат, а не поломка матрицы.

# 

# \### Что пришлось добирать отдельно

# 

# \*\*Ядро\*\* — множество векторов, которые преобразование отправляет в ноль. Это более

# точная причина необратимости, чем «ранг упал»: если k уходит в ноль, то v и v+k попадают

# в одну точку, два входа дают один выход, восстановить исходник невозможно.

# Ядро = собственное подпространство с λ = 0.

# 

# \*\*Размерности при умножении.\*\* Матрица m×n принимает n-мерный вектор и выдаёт m-мерный.

# Столбцы = вход, строки = выход.

# Правило: (m×n)·(n×p) = (m×p). Внутренние числа обязаны совпасть и схлопываются,

# внешние остаются. (5×3)·(3×8) = 5×8 работает; (3×8)·(5×3) — нет.

# Ошибся на этом в самопроверке — единственная реальная ошибка за день.

# 

# \*\*Как найти собственный вектор по известной λ.\*\* Подставить в (A − λI)v = 0 и решить.

# Каждая строка матрицы читается как уравнение: \[1, 1] означает 1·x + 1·y = 0.

# Строки после подстановки λ всегда пропорциональны, поэтому достаточно одной.

# Ответ — всегда прямая, а не точка. Быстрая формула для 2×2: v = (b, λ−a) либо (λ−d, c).

# 

# \*\*Зачем скалярное произведение в поиске по эмбеддингам.\*\* Текст превращается в вектор

# так, что близкие по смыслу тексты получают близкие направления. Косинус угла между

# векторами = мера смысловой близости. Детали — на Фазе 3.
